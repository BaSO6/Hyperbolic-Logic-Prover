# Data Directory

## Trained Artifacts (included in this repo)
These files are trained/processed outputs of this project and are included directly:

| File | Description |
|---|---|
| `hgcn_final.pth` | Trained Hyperbolic GCN checkpoint (main model) |
| `hgcn_refined.pth` | Refined HGCN checkpoint |
| `node_embeddings.pt` | 64-dim hyperbolic node embeddings (110,314 nodes) |
| `edge_index.pt` | Graph edge index for Mathlib dependency graph |
| `id_to_name.pkl.gz` | Node ID → Mathlib theorem name mapping |
| `node_list.pkl.gz` | Ordered list of all graph nodes |
| `node_head_symbols.pkl.gz` | Head symbol index for each node |
| `node_text_map.pkl.gz` | Node ID → theorem statement text |
| `mathlib_deep_graph.pkl.gz` | Full Mathlib dependency graph |
| `proof_local_deps.json` | Local proof dependency map |
| `debug_traces.jsonl` | Search traces for debugging |
| `system1_feedback.json` | System 1 training feedback data |
| `putnam.json` | Processed Putnam benchmark problems |
| `proofnet.json` | Processed ProofNet benchmark problems |

## Large Files (download separately)
These are too large for GitHub or are official public datasets. Download them before running.

### 1. Mathlib4 (required — ~5.6GB)
```bash
cd data/
git clone https://github.com/leanprover-community/mathlib4.git
cd mathlib4 && lake build  # takes ~30-60 min
```

### 2. miniF2F Benchmark (required for benchmark_minif2f.py — ~1.4GB built)
```bash
cd data/
git clone https://github.com/zhangir-azerbayev/miniF2F.git
# Then build the Lean files:
cd miniF2F && lake build
```

### 3. PutnamBench (required for benchmark_putnam.py — ~376MB)
```bash
cd data/
git clone https://github.com/trishullab/PutnamBench.git PutnamBench-main
```

### 4. ProofNet (required for benchmark_proofnet.py — ~64MB)
```bash
cd data/
git clone https://github.com/zhangir-azerbayev/ProofNet.git ProofNet-main
```

### 5. Large Embedding Files (optional — regeneratable)
These can be regenerated by running `src/system1/train.py`:
- `node_embeddings_variant_a.pt` (108MB)
- `node_features_euclidean.pt` (162MB)  
- `node_embeddings_euclidean.pt` (31MB)
- `raw_bert_embeddings.pt` (162MB)

Or download from our HuggingFace release: *(link TBD)*

### 6. LLM Model Weights (required — stored in `models/`)
Download from HuggingFace into the `models/` directory:
```bash
# Primary prover model
huggingface-cli download deepseek-ai/DeepSeek-Prover-V1.5-RL \
    --local-dir models/DeepSeek-Prover-V1.5-RL

# Optional alternative models
huggingface-cli download AI-MO/NuminaMath-72B-TIR \
    --local-dir models/NuminaMath-72B-TIR
```
